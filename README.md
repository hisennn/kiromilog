# Kiromilog

Anime and manga tracking app built with Next.js, Neon Auth, Drizzle, and Jikan data.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run db:generate
npm run db:migrate
npm run db:push
```

## Environment

Crie `.env.local` com os valores usados em `src/lib/env.ts`.

## Stack

- `next@16`
- `react@19`
- `drizzle-orm`
- `@neondatabase/auth`
- `@neondatabase/serverless`
- `zod`
